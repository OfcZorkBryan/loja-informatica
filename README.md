# Sistema de Cadastro — Loja de Informática

![Banner anime original em tons suaves](assets/anime-banner.svg)

Projeto de estudo para praticar programação, Git e GitHub com um cadastro simples de uma loja de informática.

## Organização

Os registros do exercício estão separados em arquivos de texto:

- `produtos.txt`
- `clientes.txt`
- `fornecedores.txt`

## Sobre o projeto

O repositório começou como uma versão inicial de um sistema de cadastro e recebeu atualizações nos registros. O código e as instruções de execução podem ser documentados aqui conforme o projeto evoluir.

## Privacidade dos dados

Este repositório está público. Use somente dados fictícios nos arquivos de clientes e fornecedores. Se algum registro for real, remova ou anonimize esses dados e revise o histórico do repositório.
